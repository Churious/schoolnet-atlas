# schoolnet-atlas

학교 네트워크에서 차단되는 사이트의 차단 유형을 수동 관찰로 기록하는 레포.

## 범위 (중요)

- 수동 관찰만: 브라우저에서 보이는 결과, 차단 페이지 문구(개인정보 제외), DNS 응답 유무 정도만 기록
- 금지: 무단 스캔, 우회 시도, 내부 IP/학사정보 게시, 우회법 정리
- 학교명·실명은 익명화 (예: `my-school`)

## 차단 유형 판별법 (관찰용)

같은 사이트에 대해 아래만 확인하고 기록:

1. DNS 차단인가?
   - `nslookup example.com` → NXDOMAIN / 0.0.0.0 / 차단 서버 IP면 DNS 차단 의심
   - 정상 IP가 오는데 접속 안 되면 DNS 아님
2. HTTP(S) 차단인가?
   - `curl -v https://example.com` → 연결 리셋/타임아웃 vs 차단 페이지(200 + 안내문)
   - 브라우저 개발자도구 상태 코드와 함께 기록
3. 기준 추정 금지: 카테고리만 적고 단정하지 않기 (예: `SNS 추정`, `확실함` 쓰지 않기)
